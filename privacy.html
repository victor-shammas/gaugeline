Privacy Policy

Effective date: October 1, 2026

The short version
  • Gaugeline has no accounts, no servers, no analytics and no ads.
  • It makes no network connections at all. The app doesn't even have permission to use the network.
  • It reads usage numbers that your AI coding tools already save on your Mac, and shows them to you. That data never leaves your Mac.
  • I (the developer) never receive any of your data.

This policy explains what the Gaugeline app for macOS ("Gaugeline", "the app") reads, what it stores, and what it never does. Gaugeline is made by Victor Shammas, an independent developer ("I", "me").

1. What Gaugeline reads

Gaugeline can only see folders that you explicitly choose in the standard macOS folder panel. It runs in Apple's App Sandbox, so it can't browse the rest of your Mac.

SourceWhat is readWhy
Your .claude folder (if you connect Claude Code) settings.json, to see whether Gaugeline's status line command is added, and gaugeline-rate-limits.json, the file that command saves To show your Claude Code 5-hour and weekly usage percentages and reset times.
Your .codex folder (if you connect Codex) Codex's local session logs, which Gaugeline scans only for the rate-limit snapshots Codex records. Read-only. Gaugeline never opens Codex's sign-in file (auth.json). To show your Codex 5-hour and weekly usage percentages and reset times.

Some of these files, such as Codex session logs and the data Claude Code passes to its status line, also contain other information, for example the folder you're working in or parts of your conversations. Gaugeline extracts only the usage figures (percent used, window length and reset time). It does not keep, display or transmit your prompts, your code or anything else from those files.

2. What Gaugeline changes on your Mac

  • Claude Code settings, only when you click "Add to Claude Code". Before anything changes, Gaugeline shows you the exact setting it will add. It then edits only the "statusLine" entry of ~/.claude/settings.json; everything else in the file, including its formatting, stays as it was. Before its first change it saves a copy of your file as settings.json.gaugeline-backup; that copy is created once and never overwritten. If you already had a status line, it keeps working inside Gaugeline's command, and "Remove from Claude Code" restores it exactly.
  • The status line command is a short shell script that Claude Code (not Gaugeline) runs after each reply. It saves the usage data Claude Code gives it to ~/.claude/gaugeline-rate-limits.json, readable only by your user account. It uses only standard shell tools and makes no network connections.
  • Gaugeline's own preferences (your settings, alert thresholds, folder-access bookmarks) are stored in its sandbox container on your Mac.

3. Network use

None. Gaugeline makes no network requests at all, and it is built without the macOS permission to make them. The links in Settings › About (Website, Privacy Policy, Support) open in your web browser, not in Gaugeline.

4. What Gaugeline never does

  • No accounts or sign-in with Gaugeline.
  • No analytics, telemetry, crash-reporting services, advertising or tracking SDKs.
  • No servers run by me. Nothing is uploaded to me or to any third party on my behalf.
  • No selling or sharing of data, because I don't have any of your data.
  • No tracking across apps or websites.

5. Notifications and launch at login

Usage alerts are local notifications that your Mac creates; no push server is involved. "Open Gaugeline at login" is off until you turn it on, and uses the standard macOS login-item service.

6. Apple

You buy and download Gaugeline through the Mac App Store. Apple processes your purchase under Apple's Privacy Policy. Apple may share anonymous sales and, if you opt in to sharing with developers, crash statistics with me. These never include the contents of your usage data.

7. Removing your data

  • To remove Gaugeline from Claude Code, use Settings › Claude › Remove from Claude Code before deleting the app. Your original status line, if you had one, comes back exactly, and gaugeline-rate-limits.json is deleted. If you already deleted the app, see Support for the manual steps; until then the command stays harmless.
  • To revoke folder access, use Settings › Claude › Revoke or Settings › Codex › Revoke Access.
  • To remove everything, delete Gaugeline from Applications, then delete its container folder ~/Library/Containers/com.victorshammas.gaugeline (macOS keeps this folder when you delete an app), ~/.claude/gaugeline-rate-limits.json and ~/.claude/settings.json.gaugeline-backup.

8. Children

Gaugeline is a developer tool rated 4+. It collects no personal information from anyone, including children.

9. Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date. If a change ever adds data collection, it will be announced in the app's release notes before it takes effect.
