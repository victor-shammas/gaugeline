Know your AI coding limits before you hit them.

Gaugeline puts your 5-hour and weekly usage limits in the Mac menu bar, with reset countdowns and a pace forecast that warns you when you're on track to run out early.

Coming soon to the Mac App Store $1.99 macOS 15 or later · Works with Claude Code and OpenAI Codex

Everything you need, nothing you don't.

One glance at the menu bar tells you whether to keep going, slow down or wait for the reset.

Both limit windows

The 5-hour window and the weekly limit for each tool, right in the menu bar, as percent used or percent remaining, or as tiny gauges. Show one tool or both, and pick which limits appear.

Colored bars

Green, yellow, orange, red. You can read it from across the room. The menu tells you how fresh the numbers are, and dims them if they haven't been updated for a day.

Reset countdowns

Know exactly when each window resets, down to the minute.

Pace forecast

An even-pace marker on every bar and a plain-English warning: "On pace to run out ~1d early."

Alerts

Optional notifications when a limit passes a level you choose, and when it resets.

Demo mode

Explore every feature with sample numbers before connecting anything.

How it works

Your coding tools already save your limits on your Mac. Gaugeline just shows them.

Grant folder access once

Pick your .claude and/or .codex folder in the standard macOS folder picker. Gaugeline is sandboxed and sees nothing else.

See exactly what's added

For Claude Code, Gaugeline shows you the one status line setting it adds, and adds it only when you click Add. It backs up your settings first, keeps any status line you already have, and removes itself in one click. For Codex, there's nothing to install.

Just keep coding

Every time you use those tools, the numbers update. No sign-in, no API keys, no network.

Private by design

There is no Gaugeline account, no Gaugeline server, and the app has no network access at all. Your data has nowhere to go.

  • No accounts, no sign-in
  • No analytics, tracking or ads
  • Reads only the folders you choose
  • Never reads, keeps or sends your prompts or code
  • Sandboxed, native Swift app
  • No network connections, ever

Requirements

  • macOS 15 Sequoia or later
  • Claude Code signed in with a Claude Pro or Max plan, and/or Codex signed in with a ChatGPT plan. Usage limits are reported for subscription plans, not API keys.
  • For Claude, you need Claude Code, the command-line tool. Gaugeline doesn't read usage from the Claude desktop or web apps on their own. Your limits are shared across them, though, so that usage shows up the next time Claude Code reports.
